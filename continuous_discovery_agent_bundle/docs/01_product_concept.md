# Product Concept

## 一文説明

現場の声・事業主の仮説・顧客会話・競合情報から、数字に表れる前の変化を発見し、企業固有のKPI・重点管理指標・観測シグナルを形成するAI組織学習プラットフォーム。

## コア価値

- 既存データの分析ではなく、分析可能な企業ナレッジを形成する
- AIが経営判断を代行するのではなく、人間が判断するための観測・仮説・根拠を提供する
- KPIは固定的な経営指標として扱い、重点管理指標は状況に応じて変化する観測対象として扱う
- 現場の暗黙知をLLM Wikiとして蓄積し、Research Agentの追加質問方針に反映する

## MVPスコープ

1. 共通初期質問 18問
2. 初期回答保存
3. Knowledge Agentによる企業プロファイル、KPI候補、重点管理指標候補、Research Plan生成
4. Research Agentによる追加質問
5. 追加回答に基づく候補更新
6. Cloud Storage上のLLM Wiki生成
7. BigQuery上の候補/現在定義テーブル更新

## 将来スコープ

- 継続観測による変化検出
- 週次Discovery Report
- 月次Learning Report
- 競合情報監視
- ナレッジグラフ可視化
- 年度再構成パイプライン
